# Verified primary sources and scope

Verified30October2026 against the source pages or author-hosted text. These pilot references supplement the course project's existing thematic literature review; they do not replace its >=20 recent-paper requirement.

- Mihaylov et al.,2018, OpenBookQA. The [official repository](https://github.com/allenai/OpenBookQA) separates science-fact retrieval and oracle annotated-fact assistance. Its [pinned download script](https://github.com/allenai/OpenBookQA/blob/b51971646e9371a61508d9953fc706645e194a71/scripts/download_and_prepare_data.sh) supplies the official archive URL and identifies Data/Main/openbook.txt. Repository revision b51971646e9371a61508d9953fc706645e194a71; archive and extracted file hashes are recorded locally. We download no embeddings/ConceptNet archives and install none of the historical repository dependencies.
- Robertson and Zaragoza,2009, [The Probabilistic Relevance Framework: BM25 and Beyond](https://www.staff.city.ac.uk/~sbrp622/papers/foundations_bm25_review.pdf), Foundations and Trends in Information Retrieval3(4),333–389, DOI10.1561/1500000019. Author-hosted primary source for the BM25 foundation. Our explicitly documented positive-IDF implementation is a standard lexical baseline with fixed parameters, not a new retriever.
- Jiang et al.,2023, [Active Retrieval Augmented Generation](https://aclanthology.org/2023.emnlp-main.495/), EMNLP. FLARE studies active decisions about when/what to retrieve during generation. It establishes relevant prior work; this short-answer pilot implements no FLARE mechanism.
- Jeong et al.,2024, [Adaptive-RAG: Learning to Adapt Retrieval-Augmented Large Language Models through Question Complexity](https://aclanthology.org/2024.naacl-long.389/), NAACL. This work uses a learned complexity classifier to choose among no/single/iterative retrieval strategies. Adaptive retrieval/routing is therefore established; evolving a router would require meaningful adaptation and fair simple controls, and is not automatically novel.

This pilot tests deployable fixed-corpus evidence access. Any observed gain belongs to retrieval/prompting, not evolutionary computation, because no evolutionary policy is fitted here. Diagnostic annotation hits are analysis-only and cannot guide inference. No publication-level novelty is claimed.
